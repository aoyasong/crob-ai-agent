## 问题列表-6（前端工程与流式对话）

1. 前端基座选哪套 yudao 脚手架？
   - A. Vue3 + element-plus（yudao-ui-admin-vue3）（推荐）
   - B. Vue2 + element-ui（yudao-ui-admin-vue2）
   - C. Vue3 + Vben（ant-design-vue）（yudao-ui-admin-vben）
   - D. 不用 yudao 前端脚手架，做一个独立轻量前端

2. “与 Agent 流式对话”走哪条后端通道？
   - A. 新增任务场景 CHAT：前端仍走 /api/tasks + /stream，后端新增 scenario=CHAT（推荐）
   - B. 复用现有任务场景（MARKET_ANALYSIS/PROFIT_MODEL）做“伪对话”（临时方案）
   - C. 新增独立 /api/chat SSE 接口（不走任务系统）
   - D. 前端直接请求 python-executor（绕过 java-control，不推荐）

3. 登录鉴权怎么处理？
   - A. MVP 先不接登录（沿用当前接口可匿名访问）（推荐）
   - B. 接入 yudao 登录与 token（对齐标准管理后台体验）
   - C. 接入你自定义的鉴权方式/单点
   - D. 本地 mock 假登录即可

4. 前端如何启动/交付？
   - A. 本地开发：vite dev server（端口 3000/3100 之类）
   - B. docker-compose 增加 web-admin 服务，一键 up（推荐）
   - C. A + B 都要
   - D. 只产出 build 静态资源，交给 nginx 托管
